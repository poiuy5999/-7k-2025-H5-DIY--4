直播能力：场景覆盖与合规门槛
直播模块对接微信小程序直播，支持电商带货场景。用户在观看直播时可以直接点击商品卡片下单，直播间与商城共用同一套商品库和订单体系。系统支持小程序、H5、APP多端观看与互动。

分销体系：裂变路径的设计空间
分销模块支持1-10级分销层级自由设定，佣金比例可精确到0.1%。订单完成后触发异步分润计算，递归向上查找分销链，按预设比例计算佣金并写入结算记录。

从技术架构角度看，分销系统的核心挑战在于佣金计算的准确性和实时性。当一笔订单产生时，系统需要实时计算该订单涉及的所有分销层级的佣金，并更新每个分销商的余额和业绩数据。在高并发场景下，这些计算需要通过异步队列处理，避免阻塞主交易流程。

分销商管理功能覆盖了完整的生命周期，包括分销商审核、升级审核、更换上级推荐人、更换分销商等级等操作。更换推荐人后，子团队的统计数据会实时并入新的团队，确保业绩归属的准确性。
